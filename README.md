# Python Project

Welcome to my Python programming repository! 

This space serves as a collection of my Python scripts, focusing on aerospace calculations, data research tools, and general programming practice. These projects support my coursework in the Avionics Engineering program at Bangabandhu Sheikh Mujibur Rahman Aviation and Aerospace University (BSMRAAU) and serve as a foundation for exploring autonomous systems and robotics.

## 🗂️ Current Contents
* **`TempCalc.py`**: A continuous loop utility for converting temperatures between Celsius and Fahrenheit.
* **`SpeedCalc.py`**: An aviation-focused script that converts Kilometers per Hour (km/h) into Knots (nautical miles per hour) and Miles per Hour (MPH).

## 🚀 How to Run
You do not need to compile Python files before running them. Provided you have Python installed on your system, you can execute these scripts directly from your terminal or command prompt.

1. Clone this repository or download the source files to your local machine.
2. Open your terminal and navigate to the project directory.
3. Run the scripts using the Python command:
   ```bash
   python TempCalc.py
